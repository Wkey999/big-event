# 普通搜索与 AI 搜索说明

## 普通搜索

```text
GET /article/search?keyword=Spring&pageNum=1&pageSize=10
  &categoryId=1&authorId=4&timeRange=7d&orderBy=latest
```

- 只检索 `state=1 AND deleted=0` 的文章，搜索字段为标题和摘要，不查询/返回富文本正文。
- `categoryId`、`authorId` 可选；`timeRange` 允许 `all/1d/7d/30d`（滚动时间窗）；`orderBy` 允许 `latest/popular`。
- 排序字段通过 SQL allow-list 选择，不将客户端字符串拼接进 `ORDER BY`。
- 分页最大 100 条；查询记录写入 `search_log`，只记脱敏后的关键词、筛选条件、结果数与耗时。

## AI 搜索工具

`POST /article/ask` 的 Agent 调用同一条已发布文章 SQL，工具参数包括 keyword、category、limit、timeRange 和 orderBy。时间窗在 SQL `WHERE create_time >= ?` 中执行，不能只靠提示词限制。工具最多回传 20 条文章元数据，强制过滤草稿和软删除文章；工具返回的文章进入 `browse_log.mode=ask`，用于评估问答入口带来的阅读行为。

返回的 `references` 由服务端从工具实际检索结果收集，不信任模型自报的文章编号。当前问答仍为无状态单轮；前端会话历史仅在当前页面展示，后续多轮记忆/落库需单独实现。
