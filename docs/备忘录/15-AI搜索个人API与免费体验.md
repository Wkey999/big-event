# AI 搜索：个人 API 与限额免费体验

实施日期：2026-10-19。仅面向 PC Web，保留原有文章检索工具、权限边界和引用卡片。

## 页面行为

- 点击“AI 搜索”，弹出“选择 AI 搜索方式”：平台免费体验／使用自己的 API。
- 平台模式固定使用 DeepSeek `deepseek-flash`，登录后每账号每天 3 次，同一网络每天默认 10 次，全站每天默认 100 次（本地可配置）。页面显示当前剩余次数，每天北京时间 00:00 按日期重新计数。
- 个人模式支持 DeepSeek、OpenAI、硅基流动的固定官方端点；填写模型 ID 和自己的 API Key。模型需要支持工具调用。不同模型的回答和工具调用效果可能不同，不能保证任意型号兼容。
- API Key 仅存当前标签页的 Pinia 内存，刷新或退出登录后清除。切换服务商清空表单中的模型和密钥，避免串用。服务端按次创建客户端，不缓存、写库或返回密钥。
- 保存配置不会调用模型。用户发送问题后，问题、检索元数据及按需读取的用户偏好会经本站后端发送给选定服务商。部署需使用 HTTPS。

## 免费额度和费用边界

请求显式指定 `mode=platform` 或 `mode=custom`。个人模式缺少密钥或调用失败时，不回退到平台模式。平台模式不接受混入的个人配置。

免费模式只使用独立试用配置 `app.ai-trial.api-key`，不读取或复用 `spring.ai.openai.api-key`。后台 RSS 标题翻译仍按原有管理员配置工作，和访客额度分开。

先在数据库事务内锁定全站计数行，再锁定网络计数行、账号计数行，三个上限都通过后同时增加次数并提交，随后才发起模型调用。事务不跨外部 HTTP 请求。MySQL 使用 `INSERT ... ON DUPLICATE KEY UPDATE` 获取排他锁，避免 `INSERT IGNORE` 带来的共享锁升级死锁。

额度预留位于 AgentAskService 的一次搜索边界，创建或重复获取客户端本身不扣次数。每次获得额度并准备调用模型扣一次。上游认证失败、超时等不退回次数，以免反复失败请求绕过限制；本地配置校验失败不扣次数。工具的多轮请求归属于同一次搜索，不重复扣次数，但均可能产生 Token 费用。每日记录持久化，刷新页面、服务重启或多个 JVM 不会重置；前端展示仅作提示，后端计数为准。

每轮最多 1,024 个输出 Token，最多 3 轮工具执行（最多 4 次模型请求），每轮最多 4 个工具调用；请求体限制 64,000 字节，单次连接超时 5 秒、读取超时 25 秒，不自动重试。DeepSeek 关闭思考模式，避免默认思考费用及旧版 Spring AI 不回传 reasoning_content 的兼容问题。这些限制减少消耗，但次数上限不是精确的金额预算。按 socket 对端地址实施网络日限额，不信任客户端提交的 Forwarded/X-Forwarded-For。IPv6 按 /64 合并，数据库仅存地址哈希；共享 Wi-Fi/NAT 的账号共享网络额度。反向代理部署下默认按代理地址共享额度；需由可信基础设施恢复真实对端，不能直接信任任意转发头。未实现注册验证码，账号、网络和全站额度仍不等同于完整反滥用体系。

按 2026-10-19 DeepSeek 官方峰时价格估算：未命中缓存输入 $0.30／百万 Token、输出 $1.20／百万 Token。如果整次搜索累计输入 6,000、输出 1,000 Token，约 $0.003／次，1,000 次约 $3。它是场景估算，不是已实测均值或单次价格保证；真实费用需结合服务商账单验证。来源：[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。

## 本地启用

1. 执行 `sql/migration/009_ai_trial_quota.sql`，新增 `ai_trial_daily_usage` 表，兼容 MySQL 5.7，不清空现有数据。
2. 复制根目录 `application-ai-trial.example.yml` 为 `application-ai-trial.yml`（已忽略），在本地填写独立试用密钥，再设 `enabled: true`。不要把真实密钥发到聊天或提交 Git。
3. 重启后端。也可使用环境变量 `AI_TRIAL_ENABLED=true` 和 `AI_TRIAL_API_KEY`。服务商地址固定为 DeepSeek 官方地址。

默认关闭免费体验；即使 enabled=true，缺少独立试用 Key 仍不可用，不会使用后台翻译密钥。当前机器已建表，是否开放以本地独立配置和 /article/ai/status 为准，不在文档记录真实密钥。个人 API 可直接使用。

## 接口与日志

- `GET /article/ai/providers`：返回服务商公开信息，无密钥。
- `GET /article/ai/status`：返回是否开放、模型、当前账号剩余、全站剩余、网络额度 ipDailyLimit/ipRemaining 和重置时间。
- `POST /article/ask`：问题、mode、个人模式的 aiConfig（provider/model/apiKey）；复用 JWT 登录校验。
- `ask_log` 记录平台／个人模式与实际模型标签、耗时、引用数和结果，不记录配置密钥或模型完整回答。当前尚未逐轮汇总 Token 用量，成本估计不能当作实测统计。
- 原 `/dev/echo` 服务端密钥探针默认关闭，且即使手动开启，也需要管理员身份。
