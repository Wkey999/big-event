## 2. 公开数据集准备（降低对爬虫的依赖）

**使用原则（写进论文"数据来源"一节）**
1. 先查 license 与用途限制，**只用于离线评测/训练**，不作为线上内容再分发；
2. 线上实时内容走**官方 API / RSS**，一律「摘要 + 来源署名 + 原文链接」；
3. 论文明确标注每个数据集的来源、版本与用途。

| 数据集 | 类型 | 在本项目的用途 | 许可提示 |
|---|---|---|---|
| **MIND**（Microsoft News Dataset） | 新闻推荐 + 用户行为 | **离线评测推荐/多样性/覆盖率的最佳选择**（最贴合毕设主题） | 需同意研究用途条款 |
| Adressa（挪威新闻） | 新闻点击日志 | 时效性、冷启动实验 | 研究用途 |
| TL;DR（源自 Reddit） | 摘要 | 摘要质量评测 | 研究用途 |
| Reddit 数据 | 社区文本 | 社区场景文本分析 | **官方 API（需注册）优先**；历史归档 Pushshift 现已受限，宜改用 HF 镜像数据集 |
| 知乎问答类数据集（如 Zhihu-KOL 等） | 中文问答/高赞回答 | 中文问答与摘要评测 | **须核对数据集页面声明的 license**；仅研究用途，不再分发原文 |
| THUCNews / LCSTS / CNewSum / NLPCC 摘要集 | 中文新闻/摘要 | 中文摘要基线与评测 | 学术用途为主 |
| DuReader（百度） | 中文阅读理解 | 问答检索评测 | 许可相对明确 |
| 中文维基 dump / CLUECorpus2020 | 通用语料 | 向量/检索实验（扩展） | 开放 |
| **GDELT** | 全球新闻元数据 | 「今天发生了什么」类**时效查询**（仅元数据 + 链接） | 开放 |

> ⚠️ 我不对上述数据集的许可逐一背书：**使用前以数据集官方页面声明为准**，并在论文中如实标注。

## 3. 评测方案（让论文分析部分丰满）

### 3.1 五类指标

| 类别 | 指标 | 说明 |
|---|---|---|
| 准确性 | Precision@K、Recall@K、nDCG@K、MRR | 检索/推荐排序质量（需相关性标注） |
| **多样性** | ILS（列表内相似度，越低越多样）、类别分布熵、作者/来源分布 | 避免"同一话题刷屏" |
| **覆盖率** | Item Coverage（推荐到的文章占全库比例）、User Coverage、长尾覆盖率 | 体现内容池利用效率 |
| **性能** | P50/P95/P99 响应耗时、吞吐 QPS、**AI 搜索首字延迟 TTFT** | 工程可用性 |
| 业务 | CTR、平均停留时长、完读率、搜索无结果率、**AI 回答引用命中率** | 线上埋点统计 |

### 3.2 实验设计

- **离线**：公开数据集（MIND/Adressa）+ 自建评测集 → 对比基线
  - 基线 B0：时间倒序（`mode=latest`）
  - B1：热度排序（`like_count + collect_count + view_count`）
  - B2：规则画像重排（阶段 C 已实现）
  - B3：AI 检索/问答（阶段 D，单轮）
- **在线**：埋点（`browse_log` / `user_action` / 待加 `search_log`、`ask_log`）做 A/B，统计 CTR 与停留时长
- **显著性**：配对 t 检验或 Bootstrap 置信区间（可选，但有则加分）

### 3.3 支撑表与看板

- 已有：`browse_log`（含 `mode`）、`user_action`、`user_profile`、`article` 冗余计数
- **待加（导师明确要的"检索日志统计"）**：
  - `search_log(id, user_id, keyword, filters, result_count, elapsed_ms, create_time)`
  - `ask_log(id, user_id, question, answer_len, reference_count, elapsed_ms, ttft_ms, model, create_time)`
  - `/admin` 看板：热门查询 TopN、无结果率、CTR、耗时分布、AI 问答量趋势

### 3.4 预期图表（论文实验章骨架）

1. 各方法 P@10 / nDCG@10 对比柱状图
2. 多样性（ILS）与覆盖率随 K 变化折线
3. 响应耗时 P50/P95 箱线或累计分布
4. 线上 CTR / 停留时长对比（A/B）
5. 汇总表：方法 × 五类指标

## 4. 参考文献策略（近 5 年期刊）

### 4.1 检索式（示例，按需调整年份）

- **CNKI 高级检索**：`主题=("大语言模型"+"智能体"+"检索增强生成"+"新闻推荐") AND 发表时间=2022-2027 AND 来源类别=北大核心/CSSCI`
- **Web of Science / IEEE / ACM DL**：`TS=("large language model" OR "LLM agent" OR "retrieval-augmented generation" OR "news recommendation") AND PY=2022-2027 AND DT=Article`
- 中英文各半，**期刊优先于会议/预印本**（导师要求）

### 4.2 目标期刊清单（近 5 年活跃）

- **国际期刊**：ACM TOIS、Information Processing & Management、JASIST、Information Sciences、Knowledge-Based Systems、Expert Systems with Applications、IEEE TKDE、UMUAI
- **中文核心**：《软件学报》《计算机学报》《计算机研究与发展》《中文信息学报》《自动化学报》《数据分析与知识发现》《情报学报》《计算机科学》
- 会议可少量补充（SIGIR / WSDM / CIKM / RecSys / ACL），但**不要以会议为主**

### 4.3 主题簇（文献综述的小节骨架）

1. 大语言模型与智能体（Agent）、工具调用
2. 检索增强生成（RAG）与向量检索
3. 推荐系统与**多样性/覆盖率**评测
4. 新闻/内容推荐的**时效性**与冷启动
5. 前后端工程与可观测性（检索日志、埋点、A/B）
6. AI 生成内容的合规与标识

### 4.4 数量与时效

- 开题报告参考文献一般 **15~25 篇**，其中**近 5 年占比 ≥ 60%**（导师明确要求）
