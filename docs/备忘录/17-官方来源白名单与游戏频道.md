# 备忘录 17：官方来源白名单自动发布与游戏频道

实施日期：2026-10-22。面向现有 PC Web 社区，复用链接卡片、机器作者、频道和人工审核链路。

## 来源与发布规则

| 来源 | 默认策略 | 范围 |
|---|---|---|
| GitHub 官方博客 | 自动发布 | 保留既有 AI/技术关键词与营销过滤，中文标题有效后发布 |
| DeepSeek 官方仓库 | 自动发布 | deepseek-ai/DeepInfer、deepseek-ai/deepseek-harness、deepseek-ai/DeepSeek-R1 |
| 千问官方仓库 | 自动发布 | QwenLM/Qwen3、QwenLM/qwen-code、QwenLM/BlenderWorld |
| 阮一峰、BBC Sport、Esports Insider、IT之家、少数派 | 人工审核 | 沿用原有采集与标题补译 |

白名单按固定来源和具体仓库判断；github.com 这个域名本身不授予自动发布权限。不抓取整个 GitHub，不收录 Issue、PR、普通提交或任意用户仓库。新增白名单仓库需更新 ContentFeedSource 的 repositories() 及相应测试。

官方仓库使用 GitHub 公开 REST API，收录所选仓库的首次公开时间与正式 Release；排除 fork、私有信息、草稿和预发行版本。标题用“品牌 / 项目 发布版本：tag”或“品牌 新开源项目：项目名”的确定性中文模板，无需消耗模型翻译额度，不复制 Release 正文、附件或配图。

遇到 GitHub API 403/429，按 X-RateLimit-Reset 暂停 API 请求，改读同一仓库自带的 Releases Atom。通过 GitHub /releases/latest 的官方重定向目标，仅从订阅中挑选该最新正式版本，不根据 tag 名猜测稳定性，也不跟随任意重定向。此时首次公开事件需等 API 恢复；Atom 仅提供最新正式版本。没有正式版本或窗口内没有更新时允许新增为 0，不制造资讯。

官方接口参考：[Releases API](https://docs.github.com/en/rest/releases/releases)、[匿名 API 限额](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。实际核对的公开订阅包括 https://github.com/deepseek-ai/deepseek-harness/releases.atom 与 https://github.com/QwenLM/qwen-code/releases.atom。该 Atom 端点作为可用补充通道，不视为有稳定性承诺的 API。

## 处理与审计

采集 → 校验来源/时效/去重 → 写入 feed_entry → 必要时补译 → 白名单发布 → article + article_source。

- 自动发布要求总开关开启、来源列入配置白名单、来源本身具有自动发布资格，三者同时成立。
- 英文 GitHub 博客标题翻译失败、默认频道不可用、机器作者异常或数据库异常时，保留待处理；不会绕过标题检查或降级发英文原题。
- feed_entry.auto_publish_requested 只在新采集且符合白名单时写 1，历史默认 0。初始迁移核对：69 条旧待审条目均为 0，未批量发布或修改其审核状态。
- 定时重试只挑 status=0 且 auto_publish_requested=1 的条目。达到当日采集上限时仍可重试已收录的自动待处理项；不会增加采集数量或重开被忽略的条目。
- 成功自动发布记录 publish_mode=1、reviewed_by=NULL、reviewed_at=发布时间；人工发布仍为 publish_mode=0 并保留管理员 ID。
- 自动方法是服务内部入口，没有提供跳过鉴权的 HTTP 发布参数。人工审核 API 仍要求管理员。
- 发布事务锁定条目，创建文章、保存来源快照、更新发布状态同事务完成。失败回滚，同一条目并发处理只能生成一张卡片。
- feed_run 新增 auto_published / auto_pending，管理页显示来源策略、本轮自动发布数和待处理数。待处理列表可人工修订、发布或忽略，已发布条目显示自动发布标识。

## 频道方案

“电竞”扩大为“游戏/电竞”，保留频道 ID 35 和文章、兴趣画像关联；机器作者“电竞资讯助手”改为“游戏资讯助手”。现有 Esports Insider 仍以电竞报道为主，改频道名称不意味着已经增加游戏评测或游戏新闻来源。
