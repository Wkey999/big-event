## §A 代码工单（交 OpenCode）

### A0 迁移脚本

新增 `sql/migration/003_admin_and_logs.sql`（沿用 001/002 的写法：先校验可重复执行的条件，再 ALTER/CREATE；**幂等**：先判断列/表是否存在）。

```sql
-- 用户管理补全：机器作者类型 + 登录开关
ALTER TABLE `user`
  ADD COLUMN `user_type`     tinyint NOT NULL DEFAULT 0 COMMENT '0-人类 1-机器作者',
  ADD COLUMN `login_enabled` tinyint NOT NULL DEFAULT 1 COMMENT '是否允许登录：0-否 1-是';

-- 检索日志
CREATE TABLE `search_log` (
  `id`           bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id`      bigint unsigned NOT NULL COMMENT '搜索用户',
  `keyword`      varchar(100)    NOT NULL DEFAULT '' COMMENT '关键词',
  `category_id`  bigint unsigned          DEFAULT NULL,
  `time_range`   varchar(16)     NOT NULL DEFAULT 'all' COMMENT 'all/1d/7d/30d',
  `result_count` int             NOT NULL DEFAULT 0,
  `elapsed_ms`   int             NOT NULL DEFAULT 0,
  `create_time`  datetime        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_user_time` (`user_id`, `create_time`),
  INDEX `idx_keyword` (`keyword`),
  INDEX `idx_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='检索日志';

CREATE TABLE `ask_log` (
  `id`              bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id`         bigint unsigned NOT NULL,
  `question`        varchar(200)    NOT NULL DEFAULT '',
  `answer_len`      int             NOT NULL DEFAULT 0,
  `reference_count` int             NOT NULL DEFAULT 0,
  `elapsed_ms`      int             NOT NULL DEFAULT 0,
  `ttft_ms`         int             NOT NULL DEFAULT 0 COMMENT '首字延迟，未知填 0',
  `model`           varchar(64)     NOT NULL DEFAULT '',
  `success`         tinyint         NOT NULL DEFAULT 1,
  `create_time`     datetime        NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_user_time` (`user_id`, `create_time`),
  INDEX `idx_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='AI 问答日志';
```

同时更新 `sql/big_event_init.sql`，使**新建库**与迁移后的库结构一致。

### A1 管理端并行接口（`/admin/**`）

权限：新增 `AdminInterceptor` 校验 `user.role = 1`，注册到 `/admin/**`；复用 `ThreadLocalUtils` 取当前用户。
**错误口径延续现有约定**：未登录 401；非管理员 403；资源不存在与无权限返回同一条模糊信息（防探测）。

| 方法 | 路径 | 参数/体 | 返回 |
|---|---|---|---|
| GET | `/admin/article/list` | `pageNum,pageSize,state,authorId,categoryId,keyword` | `PageBean<Article>`（**不含 content**） |
| GET | `/admin/article/{id}` | — | `Article`（含 `content`） |
| PUT | `/admin/article/{id}` | 标题/正文/频道/摘要/封面/state | 成功 |
| DELETE | `/admin/article/{id}` | — | 软删（`deleted=1`，幂等） |
| PUT | `/admin/article/{id}/state` | `{"state":0\|1}` | 上下架 |
| GET | `/admin/user/list` | `pageNum,pageSize,keyword,role,userType` | 用户分页（**不返回密码**） |
| PUT | `/admin/user/{id}/status` | `{"status":0\|1}` | 启用/禁用 |
| PUT | `/admin/user/{id}/role` | `{"role":0\|1}` | 改角色（见下"硬约束"） |
| GET | `/admin/stats/overview` | — | 用户数/文章数/草稿数/已发布数/今日新增 |
| GET | `/admin/stats/search` | `days=7` | 热门关键词 TopN、无结果率、平均耗时、日趋势 |
| GET | `/admin/stats/ask` | `days=7` | 问答量、平均耗时、平均引用数、成功率、日趋势 |

**硬约束（必须写测试）**
1. 管理员**不能修改自己的角色**、**不能禁用自己**；
2. **不能移除最后一个管理员**（库里必须始终 ≥1 个 `role=1`）；
3. `/admin/**` 对普通用户一律 403，且不泄漏资源是否存在；
4. 旧接口（现有 23 个路由）行为**零变化**。

### A2 检索日志接入点

- 普通搜索（下一批）落 `search_log`；
- `/article/ask` 落 `ask_log`：`elapsed_ms` 用总耗时；`ttft_ms` 若无法精确采集填 0；`success=0` 时也要记录（便于统计失败率）；**不得记录 prompt 全文**（`question` 已限 200 字符，注意脱敏）。
- `AskDTO` 已限制 200 字符，沿用。

## §B 数据工单（公开数据集，需求方主导）

### B1 选型（建议）

| 用途 | 数据集 | 说明 |
|---|---|---|
| **推荐/检索评测主集** | **MIND**（Microsoft News Dataset） | 含 `news.tsv`（标题/摘要/类别）与 `behaviors.tsv`（曝光点击）——天然适合算准确性、**多样性、覆盖率** |
| 中文补充 | THUCNews 或 CNewSum / LCSTS | 中文摘要与检索评测 |
| 时效性实验 | GDELT（仅元数据 + 链接） | 「今天发生了什么」类查询的时间过滤验证 |

> 使用前核对数据集官方 license，**仅用于离线评测**，不进入线上内容分发。

### B2 产出物（三件套，供评测脚本使用）

1. `corpus.tsv`：`article_id, title, summary, category, published_at`
2. `queries.tsv`：`query_id, query_text, time_range`（关键词与自然语言问句各一批）
3. `qrels.tsv`：`query_id, article_id, relevance(0~3)`（可用"点击/共现"自动生成弱标注 + 人工抽查 100 条）

### B3 指标计算骨架（Python，输出 CSV + 图）

- 准确性：`Precision@K`、`nDCG@K`、`MRR`
- 多样性：`ILS`（列表内余弦/类别重合）、类别分布熵
- 覆盖率：物品覆盖率、长尾覆盖率
- 性能：接口 P50/P95/P99（从 `search_log.elapsed_ms`、`ask_log.elapsed_ms` 取）
