# AI 模型榜单接入（2026-10-25）

顶部新增「AI 榜单」入口，页面按对话、编程建站、搜索、视觉理解、Agent 五个维度切换。数据来自 [Arena Leaderboard Dataset](https://huggingface.co/datasets/lmarena-ai/leaderboard-dataset) 的 `latest` 快照，数据集标注 CC BY 4.0。页面显示来源、官方发布日期和计分方法，保留来源链接；本站筛选了各维度 `overall` 类别并用中文呈现维度名称，没有修改原始评分与排名。

后端 `GET /leaderboard/models?dimension=text|webdev|search|vision|agent` 只请求固定的 Hugging Face Dataset Viewer `/rows` 地址，不接受任意上游 URL。首次访问读取数据，成功后缓存两小时；同步失败时最多每五分钟重试，并在已有数据时标为「最近一次成功数据」。没有可靠数据时展示空状态，不使用截图或手工数字补位。无需模型 API Key，也不产生模型调用费用。

这里的「更新」指本站定期检查**来源已发布**的榜单，并不代表模型一发布就有评测成绩。对话、建站、搜索、视觉使用 Arena Score；Agent 使用 IPS 分数。不同榜单的任务、样本和量尺不同，不要将分数混合成一个总榜。截图中的 Artificial Analysis Intelligence Index 是另一套评测；它的 [数据平台条款](https://artificialanalysis.ai/data-api/docs) 对面向访客展示原始分数有限制，所以本版仅提供跳转链接，没有镜像它的排行。

验收时检查：五个维度至少能读取一个官方最新快照；日期与来源一致；切换维度不会混合数据；上游不可用时不会显示虚构名次；页面可正常打开数据集与另一套综合评测链接。生产服务器对 `datasets-server.huggingface.co:443` 的出站访问需要单独验证。本地网络如需代理，可设置 `leaderboard.proxy-url`（例如 `http://127.0.0.1:7897`）；未设置时会读取进程的 `HTTPS_PROXY` 环境变量，生产服务器直连时两者都留空。
